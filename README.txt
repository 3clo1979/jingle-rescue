JINGLE RESCUE OUTDOOR SERVICES — WEBSITE PACKAGE

This is a complete static website. No installation, build tools, or database required.

TO PREVIEW
Extract the ZIP, then open index.html in your browser.

TO HOST
Upload index.html and the assets folder to your hosting provider's public web directory (often public_html or www). Keep the assets folder beside index.html.

TO EDIT
Text, styles, and interactive features are in index.html.
The logo and illustrative hero image are in assets/.
